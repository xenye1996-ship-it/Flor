# Админка STEM CMS

Дата: 2026-11-11  
Статус: утверждено владельцем («делай как рекомендуешь»)

## Цель
Редактировать лендинг, каталог, картинки и контакты через `/admin` без правок кода.

## Решения
- Хранение: JSON в `data/` + файлы в `public/uploads/`
- Вход: логин + пароль из `.env` (`ADMIN_LOGIN`, `ADMIN_PASSWORD`)
- Журнал: `data/audit.json` (кто, действие, когда, детали)
- URL: `/admin`

## MVP
1. Вход / выход
2. Контакты и реквизиты сайта
3. Тексты главной (hero, USP, marquee, цитата)
4. Каталог: CRUD товаров, цены, фото
5. Загрузка изображений
6. Журнал действий

## Не в MVP
Отдельные страницы «О нас / Доставка / Уход», SEO, несколько ролей.
